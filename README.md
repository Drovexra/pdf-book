# DROVEXRA — Digital Knowledge Library

Static production build ready for **GitHub Pages** and connected to **Supabase** (`public.books`, `book-covers`, and `book-pdfs`).

## Quick Deploy to GitHub Pages
1. Extract this ZIP archive and push all files (`index.html`, `404.html`, `.nojekyll`, `.github/workflows/deploy.yml`) to the root of your GitHub repository.
2. In your GitHub repository, open **Settings -> Pages**.
3. Under **Build and deployment**, select **Deploy from a branch** (`main` / `/ (root)`) or **GitHub Actions**.
4. Your live site will publish automatically.
